# 爆竹驱年：十二生肖与年兽

## 故事与旅程

岁末，年兽被“岁祟之源”裹挟，吞噬村落的灯火与年味。十二生肖散落各地的守岁灵身也受祟气影响，把赶来救援的人当作敌人。

原有三位主角收到十二生肖的求援，前来帮助村民守岁。玩家选择克劳斯夫人、廷瑟或鲁道夫，走过二十四站归乡路。沿途用年礼战斗、安抚灵怪、唤醒生肖灵身，并给孩子留下年礼，点亮家家灯火。终点是除夕岁关，与年兽决战。

二十四站沿用原地图节点，是游戏中的旅程进度，不对应真实农历日期。生肖沿用现有随机遭遇，不新增必须集齐十二位的通关条件。

## 年兽与结局

- 普通路线：击败“年兽·临岁”后进入“年兽·狂祟”。狂祟阶段仍随年味档位调整生命。胜利后年兽退回深山，村民平安迎春。
- 隐藏路线：沿用原有安抚首阶段 Boss 的条件，揭露“岁祟之源”。已招募的伙伴沿用原有助战伤害。胜利后祟源净化，年兽重获清明。

隐藏路线不要求额外收集十二生肖，不增加新弱点、爆竹克制倍率或新的 Boss 技能。

- 开场从岁安镇的春联、红灯、年货摊与团圆饭讲起，再引入年兽威胁。文字在固定的深红金边面板中分幕呈现，可自动翻页、手动继续或跳过。

- 角色选择界面保留原有舞台背景；春节街景和环境特效用于其余相关场景。
- 屋檐灯笼轻摆，天空有低频烟花，红金爆竹纸屑沿边缘飘落，窗户透出暖光。原有飘雪不再启用；地图民居带春联，宝藏改为绣福字的红福袋。
