# 爆竹驱年复刻教程详细目录

教程目标是从空 Unity 工程逐步实现当前项目的完整游玩流程：角色与存档、24 夜地图、卡牌战斗、净化伙伴、事件商店、送礼、剧情、春节表现和构建验证。以下是课程规划，不是已经写完的逐章正文；源码位置对应 [源码阅读指南](CodeGuide.md)。

建议面向掌握 C# 类、集合、委托和 Unity 基础组件的读者。章节按实现依赖排列，每章先展示本章成果，再讲数据与流程，最后实现并验收。完整美术、复杂演出和工具链放在可玩闭环之后。

## 第一篇 工程起步与整体设计

### 第01章 体验完整游戏并拆解需求

- 01.1 从标题到结局，标记玩家操作、界面和数据变化。
- 01.2 区分一局状态、单场战斗状态、永久图鉴与设置。
- 01.3 建立春节显示术语与历史英文 ID 的对照，明确复刻范围。
- 01.4 列出最小可玩版本和完整版的功能清单。

对应：主题设定、`GameRoot`、`Run`、`Battle`。验收：画出一局游戏流程，并说明战斗结束后为何还有奖励和送礼阶段。

### 第02章 创建并配置 Unity 工程

- 02.1 使用 Unity 2022.3.62f2，保持现有 URP 和包版本。
- 02.2 建立 `Assets/Sleigh` 的代码、场景、资源和编辑器目录。
- 02.3 创建主场景，认识场景 GUID、`.meta` 和构建场景列表。
- 02.4 配置像素贴图导入、点过滤、横屏预览与 Git 忽略规则。

对应：`SleighProjectSetup`、`Packages/manifest.json`、`EditorBuildSettings`。验收：打开正确主场景，版本和构建路径一致。

### 第03章 设计程序边界与屏幕流程

- 03.1 规划 `DB`、`Run`、`Battle`、`GameRoot`、`SleighStage` 的职责。
- 03.2 说明模型数据、界面显示与演出反馈的关系。
- 03.3 使用 `partial` 按职责组织同一类，解释共享私有成员与程序集限制。
- 03.4 设计标题、地图、战斗等屏幕名称与跳转条件。

对应：`GameRoot.cs`、`SleighStage.cs` 和各 `GameRoot.*.cs`。验收：能把任意新需求归到规则、界面、演出或工具层。

## 第二篇 数据配置与像素界面基础

### 第04章 建立静态定义和运行时实例

- 04.1 定义 `GiftDef`、`EnemyDef`、`ItemDef`、`EventDef` 和配置总表。
- 04.2 从 `Definitions.json` 加载数据，构建按 ID 查询的字典。
- 04.3 区分卡牌定义与 `Gift` 实例的 Uid、升级、配件和临时免费状态。
- 04.4 实现费用、数值与描述占位符替换，梳理稀有度和标记字段。

对应：`SleighData.cs`、`Definitions.json`。验收：通过一个 ID 查到卡牌定义，创建两张互不影响的实例并显示数值。

### 第05章 建立美术索引和资源加载

- 05.1 用逻辑 `type/anim/frame` 连接业务代码与实际图片路径。
- 05.2 加载基础索引，再应用春节 HUD 和地图索引覆盖。
- 05.3 处理整图 Sprite 与图集裁切、坐标和 pivot。
- 05.4 缓存纹理和 Sprite，并处理重载后原生对象失效。

对应：`DB.Frame/Sprite`、三个美术 JSON。验收：同一逻辑图标能切换春节素材，索引中没有缺失资源路径。

### 第06章 中文本地化和点阵文字

- 06.1 加载中文映射，对定义与界面字符串进行本地化。
- 06.2 理解字体图集、字符索引、字宽与 UV。
- 06.3 实现文字测宽、自动换行、对齐与网格生成。
- 06.4 将源字体和运行时字体分开，保留授权文件。

对应：`Chinese`、`ChinesePixelFont`、`PixelLabel`、`zh-CN.json`。验收：中英文混排、长描述换行和剧情文本均能显示，无缺字方块。

### 第07章 实现 UI 构建工具与输入热点

- 07.1 建立 640×360 逻辑画布及左上角坐标约定。
- 07.2 封装 Group、Rect、Sprite、Label、PanelBox 和 Button。
- 07.3 用 `Hotspot` 统一点击、悬停、按压和拖拽回调。
- 07.4 理解可见图形与射线目标，避免透明遮挡和拖拽后误点击。

对应：`SleighPixelUI.cs`、`Hotspot.cs`。验收：面板中的按钮可点击，悬停有反馈，拖拽不额外触发点击。

### 第08章 加入对象池和安全复用

- 08.1 按父容器和控件类型索引可复用对象。
- 08.2 回收时清除事件、输入状态、动态文字和动作。
- 08.3 用代次标记防止旧协程回收已被重新使用的对象。
- 08.4 区分材质资产与运行实例，明确创建者的释放职责。

对应：`PixelPoolBucket`、`PixelPoolElement`、`FloatAndDestroy`、`ActorMaterial`。验收：反复打开关闭面板不累积回调，不影响其他对象的共享材质。

## 第三篇 局内流程与最小地图

### 第09章 建立舞台和界面切换

- 09.1 创建 background、world、ui、effect、popup 等层级与引用。
- 09.2 实现 `BindStage`、`NewScreen` 与视图显示。
- 09.3 切换时关闭弹窗、清理临时输入、停止旧演出并回收对象。
- 09.4 接入主菜单与最小选人界面，暂时使用简单背景。

对应：`GameRoot`、`SleighStage`。验收：标题和选人可往返，切换后没有旧热点或弹窗残留。

### 第10章 创建一局游戏与可复现随机

- 10.1 定义 `Run`：生命、货币、年味、背包、遗物、补给和统计。
- 10.2 使用种子与 `rngState` 实现 Random、Int、Pick 和 Shuffle。
- 10.3 创建角色初始属性、起始卡组和初始遗物。
- 10.4 由路线模板生成 24 夜节点，规划难度修正。

对应：`SleighRun.cs` 的 `New`、`Template`、随机辅助方法。验收：相同角色、难度和种子产生相同起点和随机序列。

### 第11章 绘制地图与进入节点

- 11.1 依据 `Night.options` 绘制节点、连线和房屋。
- 11.2 区分当前可达、已选、已完成和未到达状态。
- 11.3 实现拖拽、滚轮、方向键和边界约束。
- 11.4 用 `EnterNode` 路由战斗、事件、休息、商店和宝箱。

对应：`GameRoot.Map.cs`、`MapDrag`、`EnterNode`。验收：只能进入当前夜的可选节点，完成后推进到下一夜。

## 第四篇 卡牌战斗规则

### 第12章 战斗单位与战斗初始化

- 12.1 定义 `Unit` 的生命、护甲、状态、意图、阵营和祟气。
- 12.2 从 `Run` 构造玩家和敌人，复制卡牌到战斗牌堆。
- 12.3 定义 `BattleCue` 和状态快照，先保留简单日志输出。
- 12.4 开始玩家回合并建立最小战斗调试界面。

对应：`SleighBattle.cs` 的 `Unit`、构造函数、`Spawn`、`Cue`。验收：可以创建普通遭遇并查看双方初始状态。

### 第13章 抽牌费用与卡牌生命周期

- 13.1 管理抽牌堆、手牌、弃牌堆和消耗牌堆。
- 13.2 处理抽牌不足、弃牌重洗、临时生成和免费卡。
- 13.3 实现 `Playable` 校验与 `Play` 的费用扣除。
- 13.4 处理出牌去向和回合结束弃牌。

对应：`Draw`、`AddToHand`、`StartTurn`、`Play`、`EndTurn`。验收：费用不足时无法出牌，牌堆轮转时卡牌数量和归属正确。

### 第14章 伤害护甲与状态结算

- 14.1 统一数值取整，计算伤害和护甲增益。
- 14.2 区分攻击、直接伤害、护甲抵挡与反伤。
- 14.3 实现状态叠加、衰减、回合触发与死亡处理。
- 14.4 以基础攻击和防御卡追踪一次完整结算。

对应：`DamageCalc`、`BlockCalc`、`Damage`、`Strike`、`Apply`、`Decay`。验收：多段攻击、反伤和状态组合的结果符合规则检查。

### 第15章 卡牌效果升级与配件

- 15.1 按卡牌 ID 分派效果，覆盖攻击、防御、抽牌和能力牌。
- 15.2 读取升级数值和动态描述，保持预览与规则一致。
- 15.3 添加配件规则、连击及特殊卡牌分支。
- 15.4 区分永久修改与单场临时状态。

对应：`Gift.Values/Description`、`ResolveGift`、`PartEffect`。验收：升级和装配件会影响正确实例，预览和实际效果对应。

### 第16章 敌人意图与回合推进

- 16.1 读取敌人动作定义、固定序列和权重选择。
- 16.2 展示下一步意图，执行敌方及友方行动。
- 16.3 处理召唤、特殊敌人与难度修正。
- 16.4 串联玩家回合结束、敌方行动、下一玩家回合和胜负判断。

对应：`ChooseIntent`、`Weighted`、`ExecuteMove`、`EndTurn`、`Check`。验收：能连续完成多个回合，意图显示与执行动作一致。

### 第17章 祟气净化与伙伴机制

- 17.1 判断年礼是否符合敌人的喜好或厌恶。
- 17.2 改变祟气格，进入软化状态并处理信任被打断。
- 17.3 完成净化、转换阵营、记录图鉴与伙伴奖励。
- 17.4 处理伙伴卡的动作步骤及已获得伙伴的升级。

对应：`PipEffect`、`ChangePips`、`SoftHurt`、`Charm`、`Run.AddFriend`。验收：战斗可通过击败或净化结束，两种结果产生对应奖励和记录。

### 第18章 角色能力遗物补给与首领

- 18.1 实现能力充能、目标选择与不同角色的能力路径。
- 18.2 按钩子执行遗物，处理补给的战内与战外使用。
- 18.3 接入十二生肖助战的现有 ID 与效果映射。
- 18.4 处理首领变身、隐藏条件及特殊胜利路径。

对应：`UsePower`、`Charge`、`UsePotion`、`Relics`、`SecretBoss`、`Transform`。验收：能力与补给只消耗一次，首领变身和胜负路径可到达。

## 第五篇 战斗界面与完整游玩闭环

### 第19章 角色卡牌与战斗 HUD

- 19.1 通过 ActorView、GiftView 创建角色和卡牌视图。

- 20.1 实现点击选牌再选目标、拖拽出牌两种操作。
- 20.2 区分卡牌、角色能力和补给的瞄准状态。
- 20.3 处理取消、结束回合确认、忙碌期锁定与快捷键。

### 第21章 播放战斗反馈与快照

- 21.2 实现 `ApplyCueFrame` 和显示用单位快照。
- 21.3 串联抽牌、出牌、命中、状态、死亡、净化和横幅协程。
- 21.4 管理快放、减少动态效果与演出完成后的跳转。

对应：`BattleCue`、`AnimateBattle`、`FlyPlayedGift`、`DiscardHandVisual`。验收：多段攻击逐次显示，死亡和首领变身不会提前切换形象。

### 第22章 奖励送礼与年味循环

- 22.1 普通战和精英战按规则生成金币、卡牌、遗物、补给和伙伴奖励。
- 22.2 用领取标记控制重复领取，区分生成奖励与重画界面。
- 22.3 生成可满足的愿望，计算年礼品质、配件和愿望加成。
- 22.4 完成送礼、压岁钱替代、最低卡组限制和下一夜保存。

对应：`GameRoot.Rewards.cs`、`Run.PickWish/Joy/LeaveGift/LeaveCookies`、`SleighInterlude`。验收：奖励不重复生成或领取，送礼确实移除永久卡牌并推进流程。

### 第23章 年俗事件休息与宝箱

- 23.1 读取事件文本、选项、价格和前置条件。
- 23.2 用 `EventOutcome` 表达文本、战斗、选牌和后续操作。
- 23.3 实现强化、复制、变换与事件送礼选择。
- 23.4 实现围炉恢复、强化、年味提升和宝箱揭示。

对应：`SleighEvents.cs`、`GameRoot.Events.cs`、`SleighInterlude.cs`。验收：选项条件有效，所有结果都能继续或结束当前节点。

### 第24章 年货商店与资源消费

- 24.1 生成商品、配件、稀有度价格与折扣。
- 24.2 检查货币、补给槽和配件适配条件。
- 24.3 处理售出、强化限次、捐赠递增和选牌返回。
- 24.4 确保重画商店保留当前商品和已售状态。

对应：`GameRoot.Shop.cs`、`Run.Spend/AddRelic/AddPotion`。验收：买过的商品不能重买，资金不足或槽位已满时不扣钱。

## 第七篇 春节视觉声音与适配

- 28.1 为卡牌映射特效风格，计算飞行轨迹与命中位置。

### 第30章 横屏视口安全区与显示设置

- 30.2 处理宽屏、窄屏和安全区，保持像素界面比例。

对应：`SleighViewportLayout`、`SleighDisplaySetup`、`LocalPointer`。验收：不同屏幕比例下主要按钮可见可点，遮罩完整覆盖。

## 第八篇 工具验证与教程交付

### 第31章 场景烘焙与资源生产工具

- 31.2 解释 `IsBaking` 和编辑器预览数据，避免写入玩家进度。
- 31.3 介绍字体烘焙、美术图集打包和音效烘焙的输入输出。

对应：`SleighSceneBaker`、`SleighSceneAuthoring`、`BakeChineseFont.py`、`BuildFestivalArt.py`。验收：在独立练习工程生成可运行的舞台，资源键与主场景路径一致。

### 第32章 自动检查与故障定位

- 32.1 运行 GUID、Resources、包引用、索引和构建路径审计。
- 32.2 编译当前源码，理解生成的 IDE 工程与实际源文件列表的区别。
- 32.3 执行完整性、玩法、主题、表现、视口、转场和材质检查。
- 32.4 在隔离副本跑 Play Mode，验证菜单脚本重载、射线和完整前半段流程。
- 32.5 使用 Runtime Diagnostics 定位可见但无法操作的按钮。

对应：`Tools/audit_project.py`、`compile_project.py`、`Editor/Validation`。验收：记录实际执行命令、退出状态和通过标记，测试不接触玩家存档。

### 第33章 Android 构建与发布前验收

- 33.1 保持现有包版本，配置横屏与主场景构建列表。
- 33.2 通过现有 Android 工具生成测试 APK，检查设备端表现。
- 33.3 验证触控、横屏切换、安全区、音频、暂停恢复和存档。
- 33.4 记录平台工具链、测试设备和构建条件，归档可复现版本。

对应：`SleighAndroidBuild.cs`、`ProjectSettings`。验收：真机能开始冒险、完成普通战、恢复存档；编辑器检查通过不替代设备验收。

### 第34章 组织完整教程与练习工程

- 34.1 每章固定结构：成果展示、前置知识、数据设计、实现、验证、练习。
- 34.2 为章节保存可运行的 Git 标签，维护章节与源码文件对照。
- 34.3 准备普通胜利、净化伙伴、首领和失败的演示存档或可复现种子。
- 34.4 整理常见错误：缺索引、缺字、空引用、回调重复、数字提前更新和菜单失效。
- 34.5 整理字体、图像、音频授权及素材来源，区分源码与教程素材交付。

验收：读者能按章节从零到完整闭环，每个阶段都有可运行成果和定位问题的办法。
